# Maya 30-Day Agent Runbook

This runbook is for validation. It does not assume €10,000/month will happen. It collects enough real data to calculate what would be required.

## Week 1 — Build the measurement loop

### Day 1
- Orchestrator: create content IDs `V001` to `V010`.
- Trend Scout: produce first Italy beauty/beauty-tech trend report.
- Product Scout: create initial candidate list but do not activate links without exact verified destinations.
- Funnel Agent: define `/shop-the-look/` brief for `V001`.
- Analytics Agent: establish the video/product metric schema.

### Day 2
- Content Strategist: choose 2 content tests from verified demand.
- Script Producer: produce 2 hook variants for each.
- Commerce & Compliance: review claims/disclosures.
- Publishing Planner: create TikTok and YouTube versions with unique UTM/content IDs.

### Days 3–7
- Publish consistently using the smallest affordable production stack.
- Record results after comparable measurement windows.
- Do not buy products merely to fill the calendar.
- Use real product footage only when a real product is actually available.

## Week 2 — Reach and intent

- Continue 1–2 original short-form tests/day depending on production capacity.
- Prioritize formats that create profile/site intent, not vanity views alone.
- Create one longer YouTube video that explains Maya or one beauty-tech topic and can carry clickable website links.
- Growth Optimizer makes first quartile ranking only after enough comparable data exists.

## Week 3 — Commerce preparation

If legitimate TikTok Shop Creator eligibility in Italy is reached:
- Commerce & Compliance verifies current eligibility from official TikTok documentation/Creator Center.
- Product Scout searches Product Marketplace for exact listings.
- Select at most 5 products to investigate.
- Prefer sample availability over purchasing inventory when legitimate and available.
- Never claim a sample was received until it is physically received.

If Shop eligibility is not reached:
- Keep building organic audience.
- Use the website for owned-product/software-affiliate tests where programs are legitimately available.

## Week 4 — Monetization test

Run at least one test from each viable engine:

### A. Commerce
- Exact product/listing verified.
- One shoppable content experiment per product angle.
- Measure product clicks -> orders -> commission.

### B. Owned digital product
- Draft `Maya AI Beauty Creator Kit` offer.
- Do not build 100 pages before testing demand.
- Publish a waitlist/preorder only if the payment/delivery terms are clear and the product can be delivered.

### C. Beauty-business service
- B2B Sales Agent selects 20 qualified businesses using public evidence.
- Create 1 personalized content/funnel idea for each.
- Send outreach manually/ethically through approved channels.
- Track replies, calls, proposals, wins, and reasons for loss.

## Core measurement table

For each platform version of each content ID, record:

`content_id | platform | publish_at | views | retention | avg_watch_time | likes | comments | shares | saves | profile_visits | site_sessions | affiliate_clicks | orders | leads | gross_revenue | commission_revenue | owned_product_revenue | notes`

## Scale/kill rule

Do not use arbitrary viral-view thresholds.

Once comparable data exists:
- Primary monetized ranking: revenue per 1,000 views.
- Pre-monetization ranking: site sessions per 1,000 views + retention.
- Top quartile: create 3 controlled variations, changing one major variable at a time.
- Bottom quartile: pause and document why.

## €10k calculation rule

Never use an assumed conversion rate as if it were observed.

After real sales exist, calculate:

`required_monthly_views = 1000 * target_revenue / observed_revenue_per_1000_views`

For mixed revenue, calculate each engine separately and combine only observed or explicitly modeled assumptions.
